## 🚀 Featured Projects

### 🎙️ VoiceRadar — Deepfake Audio Detection
A machine learning system designed to detect AI-generated and manipulated speech, evaluated across multiple speech datasets.

- Achieved **2.544% EER**, **97.46% accuracy**, and **0.9957 ROC-AUC** on an 18,480-file cross-domain test split.
- Benchmarked across ASVspoof5 Track 1, FakeOrReal, In-The-Wild, and Kaggle Deepfake Audio Detection datasets.
- Explored WavLM-Large, HuBERT, physics-informed regularization, and attentive temporal pooling.

**Focus:** Machine Learning · Audio Intelligence · Model Evaluation

### 📚 DocMind — AI Document Intelligence & RAG Platform
An AI-powered document assistant that lets users upload documents and ask questions grounded in their content.

- Built document ingestion and parsing with PDF/Tika, token-aware chunking, and metadata enrichment.
- Implemented semantic retrieval using OpenAI embeddings and PostgreSQL with pgvector HNSW cosine-similarity search.
- Added JWT authentication, per-user document isolation, persistent chat memory, source citations, and streaming responses using SSE.

**Tech Stack:** Java 21 · Spring Boot · Spring AI · PostgreSQL · pgvector · Docker

### 🏠 Zivro — AI-Powered Home Service Marketplace
A full-stack marketplace connecting users with home-service professionals.

- Implemented secure authentication using Spring Security, JWT, and Google OAuth.
- Built urgency-based pricing, location-based worker matching, and multi-step booking workflows.
- Integrated Razorpay payment-verification endpoints and Flyway schema migrations.

**Tech Stack:** Java 21 · Spring Boot · MySQL · Cloudinary · Docker
