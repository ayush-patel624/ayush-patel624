### 💼 Featured Projects

#### 🎧 [VoiceRadar — Deepfake Audio Detection System](https://github.com/maloth-anil/VoiceRadar-Voice-Deepfake-Detector)
`PyTorch` `WavLM-Large` `HuBERT` `Python`
- Production-ready deepfake audio detection achieving **2.544% EER**, **97.46% accuracy**, and **0.9957 ROC-AUC** on an 18,480-file cross-domain test split.
- Trained and benchmarked across **ASVspoof5 Track 1, FakeOrReal, In-The-Wild**, and Kaggle Deepfake Audio Detection datasets.
- Engineered a physics-informed regularization module for vocal-tract acoustics and an attentive temporal pooling layer on top of self-supervised speech backbones.

#### 🏠 [Zivro — AI-Powered Home Service Marketplace](https://github.com/ayush-patel624/Zivro---AI-Powered-House-Services) · [🔗 Live Demo](https://zivro-ai-powered-house-services.vercel.app/)
`Java 21` `Spring Boot 3.4` `Spring Security` `MySQL (Aiven)` `Google OAuth` `Cloudinary` `Docker`
- Full-stack platform with backend on **Render** and frontend on **Vercel**, integrating **Cloudinary** for media management.
- Secure **JWT-based authentication** with **Google OAuth**, schema versioning via **Flyway** on **MySQL 8.x**.
- Dynamic urgency-based price quoting, location-based worker matching, multi-step booking workflows, and **Razorpay** payment verification.

#### 🧠 [Mental Health Prediction](https://github.com/ayush-patel624/Mental-Health-Prediction) · [🔗 Live Demo](https://mental-health-predictor-kent.onrender.com/)
`Scikit-learn` `Python` `Pandas`
- Analyzed **5,000 student records** across 13 columns to predict a continuous mental health wellness score (0–10 scale) from 12 lifestyle/digital-habit metrics.
- Feature pipeline via **ColumnTransformer**, reducing categorical cardinality from 111 to 11 regions.
- Optimized a **Random Forest Regressor** via RandomizedSearchCV (15 combinations, 5-fold CV) and deployed via a REST backend.
